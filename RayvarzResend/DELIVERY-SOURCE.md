# تحویل سورس (غیرپابلیش) — نسخه آخر

اجرا با `dotnet run` از همین پوشه — بدون exe publish.

ورود کاربران: `https://city.mashhad.ir:5065/login.html`  
متن صفحه: «ورود با کد ملی و رمز عبور»  
ادمین می‌تواند با نام کاربری `admin` وارد شود (در صفحه ورود نمایش داده نمی‌شود).

تنظیمات: فقط `RayvarzResend.Web\appsettings.json`

## اجرا

```powershell
cd RayvarzResend\RayvarzResend.Web
dotnet run
```

## تغییرات این نسخه

| مورد | رفتار |
|------|--------|
| ورود | «ورود با کد ملی و رمز عبور» — بدون اشاره به admin در صفحه |
| تهاتر | فقط همان شماره‌ای که کاربر وارد کرده ارسال می‌شود |
| واسط Sara | پس از ارسال موفق: `Accounting_DocHeader` و `Accounting_DocDetails` |
| SourceId | `FinancialAssistant` — فیلد کد منبع بعد از دریافت فیش پر می‌شود |
| تب تکی | خلاصه ارسال فارسی؛ ردیف: کد درآمد / شرح / مبلغ |
| پیش‌نمایش XML | حذف |
| نتیجه ارسال | کارت داخل برنامه؛ بدون confirm مرورگر |
