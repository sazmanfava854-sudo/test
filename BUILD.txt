Path like:
  Downloads\test-cursor-ruletrace-standalone-88fc(47)\test-cursor-ruletrace-standalone-88fc

Two problems:
  1. Nested folder — build.cmd is in the INNER folder, not in (47)
  2. Parentheses (47) — cmd.exe treats (47) as grouping, so Windows
     "cannot find" build.cmd even when the file exists

DO THIS (Explorer, no script):

1. Open the INNER folder (the one that contains RuleTrace.sln)
2. Select all files (Ctrl+A)  OR  select the inner folder itself
3. Copy (Ctrl+C)
4. Open C:\
5. New folder:  C:\ruletrace
6. Paste (Ctrl+V) so you have:
     C:\ruletrace\RuleTrace.sln
     C:\ruletrace\build.cmd
     C:\ruletrace\MainForm.cs
7. In Visual Studio: File -> Open -> Project/Solution
     C:\ruletrace\RuleTrace.sln
8. Build -> Rebuild Solution     (Ctrl+Shift+B)
9. Debug -> Start Without Debugging   (Ctrl+F5)

Do NOT double-click build.cmd under Downloads.
Do NOT extract ZIP to (48) (49)...
